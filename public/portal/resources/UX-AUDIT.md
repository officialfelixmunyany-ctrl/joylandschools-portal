# Brutal UX Audit: Current Daraja Public Library

## Main problem

The current public page is visually active but decision-heavy. It asks a normal user to understand public resources, free-read limits, Google access, saved offline resources, teacher/learner/parent dashboards, and school login before the user has confidently found a resource.

## What should change

1. Make the library the first job, not login.
2. Ask one clear question first: Are you a teacher or learner?
3. Treat school login as private records only.
4. Keep search, but do not depend on search alone.
5. Use facets that match school thinking: audience, level, subject, resource type.
6. Show result cards with enough information to decide before opening.
7. Keep saved resources visible, but do not make offline saving a major first-time message.
8. Remove repeated reassurance text. Say once that public resources and school records are separate.

## Replacement IA

- Library
  - Teacher resources
  - Learner resources
  - Saved resources
- Access
  - Public reader access
  - School login for private records

## User flow

1. User lands on Library.
2. User chooses Teacher or Learner.
3. User filters by level, type, subject.
4. User opens a resource.
5. User saves it or continues to public-reader access.
6. User only goes to school login for private dashboards.
